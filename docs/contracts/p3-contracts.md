export function substitute(text: string, ctx: SubstitutionContext, mode: "prompt" | "bash" | "script" | "raw"): string
```
Grammar: `$ARGUMENTS`, `$ARTIFACTS_DIR`, `$WORKFLOW_ID`, `$RUN_ID`, `$BASE_BRANCH`, `$CONTEXT`, `$LOOP_USER_INPUT`, `$REJECTION_REASON`, `$LOOP_COUNT`, `$inputs.<key>` / `$input.<key>`, `$<nodeId>.output` and `$<nodeId>.output.<field>[.<field>]`. Objects render as JSON; in bash mode every substituted value is single-quote shell-escaped; in script mode values are inserted raw (JSON for objects, plain for strings); in prompt mode strings verbatim, objects JSON-pretty. Unknown refs are left untouched and reported via an optional `onUnknown` callback.

export async function executeWorkflow(loaded: LoadedWorkflow, deps: WorkflowRuntimeDeps, opts?: ExecuteOptions): Promise<RunResult>
```
Executor behaviour: validate inputs (required/default); walk layers; within a layer run nodes whose readiness is "run" concurrently up to maxParallel (default settings.maxConcurrentChildren); "skip" → status skipped; each node gets `$ARTIFACTS_DIR = deps.artifactsDir`; AI nodes: build the prompt (command file body or prompt text, substituted, plus schemaPromptSuffix when output_format), tools from allowed_tools/denied_tools (architect role → read-only always), context fresh (default) vs shared (resume the previous node's sessionRef in the same chain) vs {resume: id}; on output_format parse+validate, re-ask up to MAX_SCHEMA_RETRIES with the errors appended; write artifact `artifacts/nodes/<id>.md` (+ .meta.json via store.writeArtifact) with the text or JSON; bash/script nodes: substitute in their mode, run with timeout (default 120000), stdout → output (trailing newline trimmed; try JSON.parse when it looks like JSON), non-zero exit → failed; loop nodes: iterate ≤ max_iterations, fresh_context per iteration when set, stop when `until` token appears in the text (`<promise>TOKEN</promise>` or bare token) or `until_bash` exits 0; interactive loop → deps.approval per iteration with gate_message, response → $LOOP_USER_INPUT; approval nodes → deps.approval; rejected with on_reject → run the on_reject prompt as an AI node then re-ask, ≤ max_attempts (default 3), else status cancelled; cancel node → RunResult cancelled with the reason; verify/best_of/interleave/hypothesis/mcp_tool/workflow: implement `mcp_tool` via deps.mcpTool (failed when absent), `workflow` via deps.runWorkflow (failed when absent), and STUB the other four as `failed` with error "not implemented until P4" — but keep them as separate files under nodes/ so P4 fills them in; retry: on failure re-run up to retry.max_attempts (default 2) with delay_ms (default 3000) — never on loop; on_fail: retry → same as retry; cancel → cancel the run; elevate/reauthor → mark the run `failed` with error "elevation: <nodeId> failed N times" and write `artifacts/escalation-report.md` (verdict/output/error/attempts) — the freeze semantics (P4) build on this; record every node start/end as store events ("node.start"/"node.end" with status) and every agent usage as a ledger row via rowFromAgentRun-shaped data (origin "run", or "auditor"/"verifier" by role); `returns` → RunResult.returns = that node's output; dryRun → print the layer plan without running. All timeouts honour deps.signal (cancelled). Tests with a stub `agent` (scripted answers per nodeId, including one invalid-JSON-then-valid sequence), a stub `bash`, temp run dirs via RunStore, covering: layers/readiness/evaluateWhen table, substitution modes (shell quoting!), a 4-node DAG with when routing (classify → bug|feature), loop until token + until_bash, approval approve/reject/on_reject, cancel, retry, structured output re-ask then error after 3, architect read-only enforcement, artifact hand-off (second node's prompt contains the first node's artifact content, not its transcript), context shared resume passing sessionRef, escalation report on elevate.
