## cmd-ultraplan.ts (owner planning)
`registerUltraplanCommand(pi, deps: { resolveStack(codename: "ultraplan"): { stack: ModelStack; notes: string[]; vacant: string[] }; runChild; store(); cwd(ctx); notify; panel; planMode: ReturnType<typeof createPlanMode>; childTimeoutMs(); slotSpawn(slot, ctx, dir) → SpawnIdentity; recordRun(run: AgentRun): void; opinionFallback(prompt: string, ctx: any): Promise<void> /* /titan-opinion */ })` → `/ultraplan <brief> | status | answer <n> <text> | fuse | done | abort`:
1. `<brief>` → enable plan mode; open a store run {command: "ultraplan"}; write `.titan/plans/<planId>/brief.md` (planId = `plan-<UTC>-<6hex>`); grilling round 1: the architect seat (rune) runs read-only with USER_PROMPT_ULTRAPLAN_GRILL.md → numbered frontier questions, each with a recommendation (structured output v1: `{ questions: [{ n, question, recommendation, why }] }`); the panel shows them; the user answers with `/ultraplan answer <n> <text>` or accepts recommendations with `/ultraplan fuse` (unanswered → recommendations apply); answers land in `.titan/plans/<id>/answers.md`.
2. `fuse` → seats: every non-vacant fusion-role slot of the resolved ultraplan stack (≥ 3 live else deps.opinionFallback with a notify), concurrently, READONLY_TOOLS, fresh sessions, USER_PROMPT_ULTRAPLAN_SEAT.md (brief + answers + context pack: .titan/terraform/*.md, vision.md, intent.md, AGENTS.md when present) → `seats/<A..>.md` (seat letters, never model names in any prompt — test asserts); judge (gavel) with USER_PROMPT_ULTRAPLAN_JUDGE.md over the anonymous drafts → `judge.yaml` (ranking, per-seat strengths/risks, disagreements, must-keep items; parse with `yaml`); fuser (loom) with USER_PROMPT_ULTRAPLAN_FUSE.md (drafts + judge) → `fused-plan.md`; ACK round: every live seat gets fusionContextAckPrompt(runId, fusedBytes) and must answer `ACK FUSION <runId>` + the sha256 → `acks.json` {seat, ok, hash}; the fused plan ends with a "Seat ACKs" table. Every child run → deps.recordRun (ledger origin fusion|judge|fuser via role). Panel: seats table (letter, callsign, model, thinking requested↘effective, tokens, cost), judge summary, fused plan path, ACK table, vacant seats named.
3. `done` → leaves plan mode, prints `/create-workflow --from-plan <planId>` as the next step (and a `titan-plan-done` event); `abort` → aborts children, leaves plan mode; `status` → phase + paths.
Tests (ultraplan.test.ts, fake runChild + temp dirs): seat prompts contain the brief/answers and no model id; judge/fuser prompts carry seat letters only; judge model ≠ fuser model enforced (a stack where they collide → error before spawning); < 3 live seats → opinionFallback called and no fusion spawned; acks.json records one entry per seat with the expected hash; fused-plan.md written under .titan/plans/<id>/; plan-mode.test.ts: tool filtering, isSafeCommand table (safe/destructive), Plan: extraction, [DONE:n] marking, context filtering, /plan routing to ultraplan when planCommand is /ultraplan.
