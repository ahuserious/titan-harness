export const EVIDENCE_SCHEMA_VERSION = 1;

## 5. Patterns (owner patterns)
- nodes/best-of.ts: `best_of: { n (2–8, default 4), judge?: model or role, criteria?, prompt }` → n candidates: fresh sessions, callsigns `<node>-c1..cn`, same prompt (+ persona/mimeograph later), concurrently up to maxParallel; then a judge call (role "judge", output_format `{ winner: number (1-based), scores: [{candidate, score, reason}], summary }`) over the candidates (anonymized as "Candidate 1..n"; never the model names — the prompt must not contain any candidate model id: test asserts); losers archived at `artifacts/nodes/<id>/candidates/<k>.md`; output = winner text; fail closed: all candidates failed → failed "all candidates failed"; judge invalid or picks out of range after the schema re-ask → failed; candidate collapse (≥ 2 identical sha256 texts) → warning + judge still runs; every call ledgered (the executor does via runAgent). Transliterate fusion-drive's best-of-n semantics; do not import anything from it.
